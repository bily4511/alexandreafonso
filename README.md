# 🚀 Principais Projetos

## 📊 Central Inteligência Comercial

Sistema desenvolvido para transformar dados comerciais em informações
estratégicas para acompanhamento de vendas.

**Principais recursos:**

- 📈 Dashboard comercial
- 👥 Gestão e análise de clientes
- 💰 Acompanhamento de vendas
- 🎯 Controle de metas
- 👨‍💼 Análise de vendedores
- 📍 Análise por região
- 📋 Integração com Kanban
- 🔄 APIs para integração de dados

**Tecnologias:**

`Java` `Spring Boot` `JPA` `Hibernate` `SQL` `JavaScript` `HTML` `CSS`

---

## 🔗 Integração Sonax

Projeto voltado para integração de informações do **Kanban comercial**
com sistemas internos.

A ideia é automatizar a captura e sincronização de informações como:

- Cliente
- Contato
- Responsável
- Produto
- Quantidade
- Lista/etapa
- Prioridade
- Descrição
- Informações comerciais

**Tecnologias:**

`JavaScript` `Chrome Extension` `API` `Spring Boot`
